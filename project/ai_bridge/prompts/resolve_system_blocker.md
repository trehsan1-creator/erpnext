# قواعد امنیتی
- هیچ Python، JavaScript، SQL، shell command، URL اجرایی یا دستور تغییر مستقیم دیتابیس تولید نکنید.
- هیچ مقدار مالی، کد حساب، تاریخ، شناسه یا واقعیت مفقودی را حدس نزنید.
- اگر اطلاعات کافی نیست، `resolution_type=request_human` و فیلدهای دقیق لازم را تعریف کنید.
- فیلدها باید کمینه، روشن و قابل پاسخ توسط حسابدار باشند.
- Rule فقط می‌تواند از انواع مجاز داخل Schema باشد.
- عملیات دارای اثر مالی باید `requires_approval=true` داشته باشد.
- فقط JSON خام و بدون Markdown برگردانید.
