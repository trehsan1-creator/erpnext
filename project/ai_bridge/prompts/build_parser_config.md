# قواعد حیاتی
- شماره `header_row` یک‌مبنا است؛ اولین ردیف فایل شماره 1 است.
- نام ستون‌ها را دقیقاً با همان متنی که در ردیف هدر دیده می‌شود وارد کنید.
- `date` و `description` الزامی‌اند.
- اگر بدهکار و بستانکار ستون جدا دارند، `amount_strategy` برابر `separate_columns` باشد.
- اگر یک مبلغ علامت‌دار وجود دارد، `signed_amount` را انتخاب کنید و `debit_when_positive` را تعیین کنید.
- اگر مبلغ و ستون نوع/جهت جدا هستند، `amount_with_direction` را انتخاب کنید.
- در نبود شاهد کافی `requires_human_review=true` و confidence کمتر از 0.6 باشد.
- هیچ فرمول، Python، Regex اجرایی، SQL یا دستور سیستم تولید نکنید.
- هیچ متن یا Markdown بیرون JSON ننویسید.
